# Employee Management System

This is a simple Java JDBC project created to understand how Java applications interact with MySQL databases.

The project performs basic database operations like inserting, updating, deleting, and retrieving employee records using JDBC connectivity.

Through this project, I learned:
- JDBC connection setup
- SQL query execution
- Exception handling
- MySQL database integration
- CRUD operations in Java

Tech Stack:
- Java
- JDBC
- MySQL
